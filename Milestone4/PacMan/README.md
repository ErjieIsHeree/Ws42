# Pac-Man

## Description

**Pac-Man** is a complete, playable recreation of the classic 1980 Namco
arcade game, written in Python 3.10+ using object-oriented programming, a
simple graphical library (MLX or equivalent), and a modular, reusable
architecture.

The goal of the project is to build a polished game with modern project
structure and organization, from configuration handling to packaging, and
to deploy it on a public gaming platform (such as Itch.io or Steam) as a
free, unlisted build.
